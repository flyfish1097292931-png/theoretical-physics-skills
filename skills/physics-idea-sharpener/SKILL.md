# Physics idea sharpener

Use when an intuition is interesting but has not yet specified what must be explained, calculated, or ruled out. Work with the original question before substituting an easier one.

1. **Name the tension.** Write what two expectations disagree about. Say what is held fixed, what is varied, and which response would differ. Separate a suggestive analogy from a claim about the mechanism.
2. **Define the object.** State the observable and its domain. If the idea relates two descriptions, define the object on each side independently and state what relationship is sought: equality, operational reconstruction, or a shared mechanism. An unexplained symbol stays unknown.
3. **Keep the obstruction in the toy model.** Strip away any degree of freedom that cannot change the decision, but keep any constraint, limit, or sector the ambiguity depends on. Include a baseline or competing explanation, and write one prediction that differs between the two.
4. **Name the smallest decisive move.** Pick one calculation, limiting case, or counterexample. State what result would support, reject, or leave the idea undecided. If the leading behavior cannot distinguish candidates, find the first term or observation that can.
5. **Check what is already known.** Use the [literature workflow](../hep-th-literature-workflow/SKILL.md) before claiming novelty. Once the comparison is defined, carry it into [pre-claim registration](../physics-preclaim-registration/SKILL.md) before reading decisive results.

Return a question, the smallest model that preserves it, the two predictions, and the decisive check. Keep a question open if no check discriminates. See the [worked review](../../examples/oscillator/research-review.md).
